# 对话式 AI 员工工作空间

基于 PRD V0.4 的本地 MVP。界面以对话为中心，支持独立会话、员工实例、Skill Pack、技能方案、Blueprint，以及多员工任务调度。首个验收场景是生成可预览的交互式 Web 应用。

## 启动

需要 Node.js 24 或更高版本，不需要安装依赖。进入项目目录后运行：

```powershell
npm start
```

浏览器打开 [AI 员工工作空间](http://127.0.0.1:4173/)。生成的 HTML 会在任务卡片和右侧文件区显示「打开应用 ↗」，点击即可在新页面交互。数据保存在 `data/workspace.db`，默认仅监听本机地址。预览页面使用独立的 <http://127.0.0.1:4174/> 地址，让生成页面使用自己的浏览器本地存储，同时与工作空间接口隔离。

线上工作空间位于 [https://www.zenanxing.cloud/agentmanager/](https://www.zenanxing.cloud/agentmanager/)，打开后直接进入工作空间。线上生成的交互页面使用独立的 `https://47.83.139.234/app/...` 地址预览。服务器数据保存在 `/var/lib/ai-employee-workspace/workspace.db`，与本地数据分开。该线上地址目前公开可访问，使用者可以查看会话与文件并调用已连接的模型。

## 配置 DeepSeek

1. 在 [DeepSeek 开发者平台](https://platform.deepseek.com/api_keys) 创建 API 密钥。
2. 打开应用左侧的「设置」，将「模型服务」改为 **DeepSeek**。
3. 选择 `deepseek-flash` 或 `deepseek-v4-pro`，在密码框输入密钥，点击「保存当前连接」。
4. 点击「测试连接」。测试会向 DeepSeek 发送一条很短的请求，成功后可回到对话开始任务。

通过设置页输入的密钥仅保存在当前服务进程内存中，重启后需要重新输入。若要在重启后自动连接，请在**启动服务前**设置环境变量 `DEEPSEEK_API_KEY`；可用 `DEEPSEEK_MODEL` 选择模型、`AI_PROVIDER=deepseek` 指定默认服务。Kimi 对应 `MOONSHOT_API_KEY` 和 `MOONSHOT_MODEL`。密钥不会写入数据库、Skill 文件或任务日志。

## 使用流程

1. 新建对话；系统会自动创建主管员工。
2. 点击「一键配置开发团队」，加入前端、后端、测试员工。
3. 在 Skill 市场安装并启用「网页开发」等技能。
4. 输入 `/网页开发 @小克 @小智 @小K 开发一个记账 Web 应用`，或直接输入目标让主管使用当前团队。
5. 前端、后端和测试准备工作并行执行；测试集成检查等待前后端产物完成后自动继续。
6. 任务卡片显示总进度、工作清单、团队小日报和员工进度。可并行工作先显示为建议，只有人工审核通过后才会加入任务。
7. 产物出现在右侧文件区。HTML 可点击「打开应用 ↗」直接使用，其他文本文件可预览或下载。
8. 任务完成后查看交付包：它列出产物、已经做过的静态检查和仍未运行的验证。点击「接受交付」或填写修改意见；修改会创建关联的新任务，原交付保留。任务进行中可点击「补充要求」，尚未开始的步骤会读取补充内容。

通过 `/` 调用的技能只用于本次任务，不会自动装备到员工。会话中的员工修改只影响当前会话；Blueprint 和全局档案分别保存。

## 已实现与当前边界

- 会话数据、任务、文件与员工实例按会话隔离；删除会话不删除全局档案与技能。
- 任务并发、依赖等待、失败收束、取消、重试和服务重启后的未完成任务恢复。
- 文本附件会进入当前会话的模型上下文；单个文件上限 5 MB。二进制附件目前只传文件名，尚未解析 PDF、图片等内容。
- Web 应用生成目前交付独立 HTML、后端代码和静态检查报告。系统不执行模型生成的后端代码，也不自动部署。测试员工的检查报告应视为静态审阅，实际运行测试仍需人工或后续沙盒执行能力。
- 进度百分比按已完成的清单项计算，不代表模型内部生成进度。预览链接需要对应的本地或线上服务持续运行。
- 交付审核发生在本工作空间内，不会创建 GitHub PR。HTML 结构和 JavaScript 语法属于静态检查；浏览器操作、前后端联通和自动化测试没有运行时会明确标为“未运行”。
- 技能市场目前由内置 Skill Pack 构成；权限声明、依赖和冲突检查的基础结构已具备，高风险外部操作和第三方市场尚未开放。
- 未输入有效模型密钥时，员工管理等本地功能仍可使用；任务不会伪装成已执行。真实 DeepSeek/Kimi 调用需要相应平台账号与可用额度。
